# IDM Companies – Real Estate Platform

A modernized, responsive, and 3D-animated web platform for **IDM Companies**—an integrated real estate development, in-house construction, and residential property management firm established in 1993.

## ✨ Features

- **Interactive 3D Architectural Monolith**: Procedural 3D structure with wireframe overlays and mouse-reactive lighting powered by Three.js & React Three Fiber.
- **The Integrated Model**: Interactive 4-pillar showcase detailing IDM's self-performing lifecycle:
  1. *Site Acquisition & Land Planning*
  2. *In-House Construction & Engineering*
  3. *Elevated Concierge Property Management*
  4. *Capital & Investment Growth*
- **Signature Portfolio Matrix**: Filterable showcase covering **Acero Communities**, **Meritum Living**, and **Commercial Flex Spaces** across Arizona and Washington.
- **Residence & Floor Plan Explorer**: Interactive unit plan browser featuring 1-bed, 2-bed, and 3-bed layouts with architectural highlights.
- **Dual Regional Hubs**: Showcasing operations across the **Southwest (Scottsdale/Phoenix, AZ)** and the **Pacific Northwest (Vancouver, WA / Portland Metro)**.
- **Culture & Impact**: Highlighting the **IDM Cares** volunteerism initiative and workplace excellence.
- **Dual Conversion Gateways**: Segmented inquiry form for **Capital/Land Partners** vs. **Prospective Residents**.

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router, TypeScript)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **3D Graphics**: [Three.js](https://threejs.org/) & [React Three Fiber](https://r3f.docs.pmnd.rs/) (`@react-three/drei`)
- **Animation**: Smooth CSS transitions & kinetic typography

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ installed

### Installation

```bash
git clone https://github.com/vuggidisaivarshith/idm.git
cd idm
npm install
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

### Building for Production

```bash
npm run build
npm run start
```
